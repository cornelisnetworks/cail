# Cornelis Networks Internal

`CN_INTERNAL/` is the standard Cornelis Networks internal directory for
architecture and design documentation, AI agent notes, and internal scripts.

Everything under `CN_INTERNAL/` is exempt from upstream pushes and release
archives. The `export-ignore` attributes exclude it from Git release archives;
upstream pushes must omit these files separately.

Start with the [CAIL design documentation](docs/INDEX.md).
